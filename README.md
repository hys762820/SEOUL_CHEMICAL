# 서울케미칼 업무 자동화

강설 예보 안내 팩스와 입찰·시장 동향 보고를 한 앱으로 만드는 프로토타입.

## 시작

1. 저장소를 받아 내 브랜치로 바꾸고 `origin/develop`을 합침.
2. 병합 담당자에게 받은 `.env.local`을 맨 위 폴더에 넣음.
3. `npm install` → `npm run dev` → <http://localhost:3000>에서 구글 로그인.

## 명령

- `npm run dev`: 개발 서버 켜기
- `npm run db:apply`: 내 표 파일과 샘플 데이터를 개발 DB에 반영
